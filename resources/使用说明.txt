  AbaoZip — 分卷独立解压打包工具
═══════════════════════════════════════════

【使用方法】
  双击 AbaoZip.exe 即可运行。

  打包：选择文件夹 → 设置分卷大小 → 开始打包
  解压：切换到"解压"标签页 → 选择任意一个分卷 ZIP → 开始解压
        也可以直接双击输出目录中的「一键全部解压.bat」

【如果无法运行 / 被 Windows 安全拦截】
  方法一：右键 AbaoZip.exe → 属性 → 勾选底部「解除锁定」→ 确定
  方法二：若没有「解除锁定」选项，请按 Win+X 打开 PowerShell，执行：
          Unblock-File -Path "AbaoZip.exe的完整路径"
          例如：Unblock-File -Path "C:\Users\你的用户名\Desktop\AbaoZip\AbaoZip.exe"

【为什么会被拦截？】
  本软件为个人开发的开源软件，未购买商业代码签名证书，
  Windows SmartScreen 会对未签名的程序弹出安全警告，这是正常现象。
  本软件源代码完全公开，可在 GitHub 查看：
  https://github.com/Xinabao/AbaoZip

【功能说明】
  · 将大文件夹按指定大小分卷打包
  · 每个分卷都是独立的 ZIP，可单独解压
  · 支持密码加密（ZipCrypto 兼容 Windows / AES-256 更安全）
  · 多线程并行压缩，充分利用多核 CPU
  · 64MB 分块缓冲写盘，减少磁盘碎片和 I/O 争抢
  · 打包完成后自动生成「一键全部解压.bat」脚本
  · 内置解压功能，选择任意一个分卷即可解压全部
