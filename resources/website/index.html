Features

Everything you need.
Nothing you don't.

Purpose-built for one job: splitting folders into independently extractable volumes.

📦

Independent Volume Extraction

Every volume is a complete, self-contained ZIP file. Extract any single part without needing the others — no merging, no reassembly, no special software required.

🔐

Dual Encryption Modes

ZipCrypto — compatible with Windows 10/11 Explorer for direct extraction. AES-256 — maximum security, works with 7-Zip and WinRAR.

⚡

Multi-threaded Packing

Compresses multiple volumes in parallel across all CPU cores. 64MB buffered I/O with serialized disk writes to minimize fragmentation.

📂

Multi-format Extraction

Built-in extractor handles ZIP, 7z, and RAR archives. Auto-detects AbaoSplitZip volume sets and extracts all parts together.

🌍

9 Languages

Auto-detects your system language. Supports Simplified Chinese, Traditional Chinese, English, Japanese, Korean, German, French, Spanish, and Portuguese.

💻

Cross-platform

Native builds for Windows, macOS, and Linux. Single-file executable — no installation required. Just download and run.

How It Works

Simple by design.

Unlike traditional split archives that require all parts to extract, AbaoSplitZip distributes files across volumes intelligently.

01

Scan & Sort

Scans the source folder recursively and sorts all files by size (largest first) for optimal bin packing.

02

Smart Distribution

Uses a First-Fit Decreasing algorithm to assign files to volumes. Each file stays complete — never split across volumes. Volume sizes closely match your target.

03

Parallel Compression

Each volume is compressed independently on a separate thread. Buffered writes (64MB chunks) with a shared lock prevent disk I/O contention.

04

Ready to Use

Output includes numbered ZIP volumes plus a batch script for one-click extraction of all parts. Each volume works on its own — share just the parts you need.

Usage Guide

Pack. Extract. Done.

  1. 1Select source folder — Choose the folder you want to pack
  2. 2Select output directory — Where the volume ZIPs will be saved
  3. 3Set volume size — Target size per volume in MB (sizes are approximate to keep files intact)
  4. 4Set password (optional) — Enter a password and choose encryption: ZipCrypto for Windows Explorer compatibility, or AES-256 for maximum security
  5. 5Choose compression level — Store only, Fast, Normal, or Maximum
  6. 6Click Start — Watch the progress bar and log as volumes are packed in parallel

  1. 1Select archive file — Choose any volume ZIP (e.g. MyFolder_part001.zip), a 7z file, or a RAR file
  2. 2Select output directory — Where to extract the files
  3. 3Enter password (if encrypted) — Enter the password used during packing
  4. 4Click Start — For ZIP volumes, all matching parts are auto-detected and extracted together

💡 You can also double-click the generated Extract_All.bat script to extract all volumes at once without opening the app.
