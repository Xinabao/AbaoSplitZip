AbaoSplitZip

Split large folders into independent volumes. Extract any part without needing the others.

Download Latest View on GitHub
Supported on: Windows • macOS • Linux

📦 Independent Extraction

Each volume is a complete ZIP file. Share any part, and the recipient can extract it immediately without needing the rest.

📂 Directory Priority

Smart packing algorithm keeps subfolders together whenever possible, preserving your file structure cleanly across volumes.

🔗 Merge & Extract

Received multiple parts? Just drag any one of them into AbaoSplitZip, and it will automatically find and merge all related volumes.

🔐 Secure Encryption

Protect your data with standard ZipCrypto or military-grade AES-256 encryption. Compatible with 7-Zip and WinRAR.

⚡ Multi-threaded

Optimized for modern multi-core processors. Compresses files in parallel for maximum speed.

🚫 Smart Exclusion

Automatically filter out unnecessary files (like .git, .tmp, .DS_Store) using simple wildcard patterns.

How to Use

  1. Select Source: Drag and drop the folder you want to split.
  2. Set Volume Size: Choose the size limit for each part (e.g., 700MB for CDs).
  3. Start Packing: Click "Start Pack". AbaoSplitZip will create independent .zip files (Part001, Part002...).

Tip: Use the "Merge & Extract" tab to reassemble split volumes effortlessly.

AbaoSplitZip is free and open source software.
